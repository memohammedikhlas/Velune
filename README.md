# Velune

A minimalist Android launcher with a built-in focus/session timer, inspired by "minimalist phone: Launcher".

## Features
- Minimal home screen with clock, date, and favorite apps
- Full app drawer with search, hide, and favorite
- Session-based blocker for distracting apps (Instagram, WhatsApp, etc.)
- Focus stats: total minutes, sessions, streak

## Download
Grab the latest APK from the [Releases](../../releases) page — no Play Store needed.

## Build locally
```
git clone <your-repo-url>
cd Velune
./gradlew assembleDebug
```
APK output: `app/build/outputs/apk/debug/app-debug.apk`
